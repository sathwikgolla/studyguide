# 📌 Overview

**PrepFlow** is a modern placement preparation platform designed to organize learning into a clean, trackable, and interactive experience.

Instead of scattered notes and random preparation, PrepFlow provides:

✨ Structured Roadmaps  
📚 Organized Learning Modules  
📊 Progress Tracking  
🧠 Revision & Notes System  
🎯 Placement-Oriented Learning Experience

# ⚙️ Installation

# 1️⃣ Clone Repository

```bash
git clone https://github.com/sathwikgolla/studyguide.git
```

---

# 2️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

# 3️⃣ Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

# 🌍 Environment Variables

# Backend `.env`

```env
PORT=5000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key
JWT_EXPIRES_IN=7d

NODE_ENV=development
```

---

# Frontend `.env`

```env
VITE_API_URL=http://localhost:5000/api
```
